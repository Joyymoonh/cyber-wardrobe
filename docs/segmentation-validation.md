# 衣物目标分割修复

原 SegFormer 人体穿着解析对挂拍、商品拼图不稳定。通用前景去背景也会保留手和人台，未作为上线方案。

改用本地 SlimSAM 目标分割：用户在衣物主体、袖子上点保留，在手、背景或相邻衣物上点排除；所有选点必须满足才提供采用结果。候选全部冲突、范围异常或失败时保留原图，明确报错。不会生成或补画被遮挡的衣服，不自动保存。

模型：Xenova/slimsam-77-uniform，固定版本 5850ab45f587c112167512ffef949107115e26a0，权重约13MB。模型配置与来源见 public/models/slimsam/SOURCE.md。浏览器单线程 WASM worker，推理不上传原图。

本机以用户明确授权的三张真实上衣照片对照测试：单点对多衣物和人台仍有误选，因此采用保留/排除点，并拦截不满足选点的候选。边缘、细带、遮挡和相邻同色衣物仍需人工核对，不能称为任意照片全自动精准提取。诊断图片仅保存在本机临时目录，未提交仓库或改变云端衣柜。

类型、代码检查、65项测试、生产构建通过。线上浏览器推理验证需在本版本部署后进行。
