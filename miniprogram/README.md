# 奶油衣柜 · 微信小程序体验版

这是原生小程序代码，复用项目现有 Next.js 后端；不是已经发布的小程序，也不使用 web-view 套壳。现有网页账号可使用邮箱登录；微信登录创建独立账号，暂不做账号合并。

## 已接入

- 邮箱登录、邀请码注册、微信 code 换登录令牌、退出撤销令牌。
- 衣柜搜索、分类、收藏；拍照/相册上传、编辑、删除确认、离开未保存提醒。
- 分类分割、卡通生成；结果核对后采用、三图分别保留；已有分割图优先作为卡通生成源。处理中防重复提交，失败保留草稿。
- 风格/季节/场景搭配、固定男女卡通人偶分类配色示意、单品搭配板、穿搭收藏。
- 手动身材档案、独立识别/搭配和生图 BYOK 配置、加密保存、移除配置。
- 照片通过带登录令牌的下载取得临时文件，不公开图片地址。

人偶为简化绘图，未将真实生成图变形成衣服贴到身体上；款式以单品图为准。暂不提供购物链接导入、摄像头身材扫描和真实虚拟试衣。模型准确率及付费生图质量需另行实测。

## 本地导入

1. 安装微信开发者工具，导入本目录。`project.config.json` 已配置 AppID `wx3442797deb0a35db`。导入后需要使用该小程序管理员或有开发权限的微信扫码登录。
2. 启动项目后端（保留原有 DATA_DIR 和 APP_SECRET，避免丢失现有数据或密钥解密失败）。开发时可以使用 `npm run dev`；已有生产构建可使用 `npm start`。
3. `config.js` 默认 `http://127.0.0.1:3000`，仅供同机开发者工具调试。在开发工具本地设置中按需临时关闭合法域名校验；这不是手机体验版的部署办法。
4. 后端配置 `MINI_INVITE_CODE` 后才允许小程序新用户注册；现有邮箱账号无需邀请码即可登录。
5. 用已有账号测试登录 → 添加照片 → 选分类 → 分割并核对 → 保存 → 收藏编辑 → 生成搭配。卡通化先配置自己的生图 API。
