# 两人临时网页试用

这是独立的网页版试用环境，不是微信小程序体验版。数据在 `data/pilot/`，不复制原衣柜照片或密钥。预放 8 件分类配色演示衣服，真实照片可由体验者主动上传；分割模型复用已有本地模型文件。

启动：在项目根目录执行 `node scripts/start-pilot.mjs`。服务仅监听 127.0.0.1:3001。凭据位于忽略提交且权限受限的 `data/pilot/access.json`，该文件含加密主密钥，不可整体转发。只分享登录邮箱和密码。不要更改或删除该文件，否则已有密钥可能无法解密。

本机验证：`node scripts/check-pilot.mjs`。得到临时 HTTPS 链接后，以该链接作为参数再次验证。检查登录、Secure Cookie、衣柜读取、匿名401、公开注册403、规则生成。

临时隧道需用户明确同意第三方转发登录请求和照片后再开启；用户数据存储在本机不等于中转方无法处理流量。网站需要登录，关闭公开注册，使用独立随机密码。只发给指定体验者，不公开发布。

电脑必须保持开机、联网，并同时运行服务和隧道。隧道重启/到期后地址可能变化。停止隧道即结束外网访问，数据仍保留在本机。暂时不要配置付费模型，默认规则搭配免费；生图需自行配置Key且可能收费。

本次已通过本机检查：8件衣物、3套规则搭配、匿名访问拦截、关闭公开注册和Secure Cookie。公网链接尚待生成及验证，不能称为已上线。

已建立经用户授权的 localhost.run 隧道，并从外网验证 HTTPS 登录、8件衣物、3套规则搭配、Secure Cookie、匿名访问拦截和关闭公开注册。最新地址记录于忽略提交的 data/pilot/share.json。

故障记录：免费隧道在SSH连接未断开的情况下也会自动更换域名。旧链接返回502，本机服务正常。新链接经登录、衣柜和搭配验证通过，账号与数据保持不变。此方案仅适用于短时体验，不保证固定网址；不能仅用防休眠措施保证链接持续有效。

性能排查：同一登录页面本机约0.005秒，localhost.run外网约3.77秒，页面传输约2.9KB/秒。说明当前主要受中转线路延迟/限速影响；优化页面动画无法消除该瓶颈。准备Cloudflare临时隧道对比测试，需要用户批准新中转目的地后才建立连接，不能提前承诺新线路一定更快。

经用户明确授权，已切换Cloudflare临时隧道。登录页、脚本、登录、8件衣物、3套规则搭配、匿名拦截与关闭注册均检查通过。连续页面实测4.551、0.544、3.265秒，小JS脚本1.259秒。网络仍有波动，不能承诺不卡；浏览器自动化连接超时，未完成新入口的浏览器交互验证。新地址记录于data/pilot/share.json。
