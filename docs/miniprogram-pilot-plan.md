# 奶油衣柜小程序：低成本体验版上线方案

设计日期：2026-11-03。状态：方案，尚未开通或部署云资源。

## 目标与边界

先供邀请人和一名体验成员使用，目标是托管支出 0 元；生图等外部 API 的费用另算，不承诺所有功能永久免费。免费资格、资源额度、可用期限和超额行为以账号实际控制台为准。没有满足条件的免费环境时停止开通，先保留本地版，不自行转付费。

体验版只供指定成员扫码使用，不等于通过审核的公开正式版。备案、类目、隐私配置及体验成员规则逐项按微信后台当前要求确认。

## 推荐架构

采用原生小程序 + 微信云开发 CloudBase：wx.cloud.callFunction 调用云函数，云数据库保存结构化数据，私有云存储保存照片。小程序客户端不直接持有云管理密钥，也不直接调用任意用户提供的第三方模型地址。

不购买服务器和域名；首选微信原生云调用通道。不要先将现有 Next.js + SQLite 容器搬入临时磁盘服务；重启后数据可能丢失，持续运行的容器也可能消耗额度。网页版继续使用本机原有数据，体验版作为独立环境，不强制迁移个人数据。

目录建议：保留 miniprogram/；新增 cloudfunctions/ 与可复用的领域逻辑包。将规则搭配、分类、图片提示词与人偶位置配置共享；Node SQLite、Next.js cookies/headers 不进入云函数。保留 api 适配层，使页面不直接依赖数据库结构。

## 功能和成本策略

| 功能 | 体验版策略 |
| --- | --- |
| 登录 | 微信登录，服务端从可信调用上下文获取 OPENID，客户端传入的用户 ID 不作为身份凭证。邀请码首次激活，最多 2 个体验用户。 |
| 衣柜 | 添加/编辑/删除、分类/搜索/收藏，云数据库按用户隔离。列表分页，每页 20 件，避免全库读取。 |
| 照片 | 相册/拍照，本地压缩至最长边约 1200 像素，服务器校验实际格式/字节数，处理前后均有限额。每人先最多 100 件、单文件最多 2MB。原图保留，每件最多一张有效分割图和卡通图。 |
| 搭配 | 默认运行现有规则算法，不消耗模型 API；可选用户自带文字模型 Key。固定男女卡通人偶显示分类与配色，真实款式看单品图。 |
| 卡通化 | 默认关闭；用户配置 Key 后主动点击才调用，先显示可能收费提示。每人每天最多 3 次，拒绝并发重复任务，不自动重试付费请求。 |
| 自动分割 | 保留目标，独立 CPU 云函数/处理服务先做兼容性与内存、耗时、包体测试。只有能在账号免费额度和运行限制内完成时才启用，每人每天最多 3 次。若不满足则明确显示暂不可用，不自动购买计算资源。 |
| 身材 | 先手动填写；不加入实时扫描或真实虚拟试衣。 |
| 链接导入 | 不纳入体验版。 |

应用限额是保守的初始产品限制，不是平台免费额度的推算结果。领取实际套餐后按计算/存储/下载/数据库各项额度重新核算。

## 数据与密钥

集合建议：users、items、outfits、body_profiles、model_configs、image_tasks、usage_counters。items 保存 originalFileID、cutoutFileID、cartoonFileID、imageMode、ownerOpenid、createdAt。

敏感数据只通过服务端云函数读写；数据库规则及存储规则禁止匿名访问和跨用户读取，不仅在前端过滤。私有图片读取由身份校验后的短时地址或平台授权机制完成，不持久保存公开链接。

API Key 使用稳定的服务端加密密钥加密，密钥放环境配置，响应与日志不返回明文。任意用户提供的模型地址继续做公网地址校验、每次跳转校验、超时和响应大小限制，不访问云服务内网。服务端管理凭证、AppSecret 不写入小程序包。

首次登录不自动导入本机资料。需要迁移时只迁移经确认的账号/照片范围；体验版可优先使用演示衣物或重新上传。

## 异步图片处理

生图与分割不要保持前台请求等待两分钟。小程序提交任务后获得 taskId，后台执行，前台可返回衣柜并按需查询。使用用户、操作类型和请求标识实现幂等，重复点击复用任务，不重复扣费。保存草稿版本，任务完成不覆盖用户后续编辑。失败显示明确原因，允许用户主动重试；超时后不自动再次调用可能收费的服务。

临时结果未采用时定期清理；替换或删除衣物后清理不再引用的文件。任务及额度由服务端校验，计数并发更新不能依赖客户端。

## 分阶段执行

1. 查资格：管理员进入微信开发者工具的云开发入口，查看实际免费环境、存储/计算配额、期限、超额处理与自动续费选项。在提交任何协议或收费步骤前由用户确认，不自动绑定支付或升级。
2. 云端基础：微信身份、邀请白名单、数据库、私有图片上传、衣物管理、规则搭配、人偶和收藏。优先完成无需外部模型的手机闭环。
3. 模型能力：迁移加密 BYOK 设置及异步任务；接入用户主动调用的卡通化，运行免费资源内的分割性能实验。实测后决定是否开放分割；未通过时明确降级。
4. 手机验收：两名账号互相无法访问图片/数据；登录、上传、编辑收藏、生成保存搭配、断网重试及重复点击不重复创建。验证删除清理、密钥不回显、任务晚返回不覆盖修改。
5. 上传体验版：填写隐私保护指引与联系渠道；真实 AppID 编译，恢复正式环境校验，确认客户端不含 localhost 或服务端秘密。上传开发版本，在后台按规则选为体验版并添加体验成员，分享体验码。

## 防止意外花费

优先选择额度耗尽即停服/限额的免费环境；如果平台无法保证硬上限，不将费用告警描述成预算封顶，也不在未告知风险时承诺 0 元。控制台无法关闭的超额计费是开通决策的阻塞条件。

不启用自动升级、自动续费或按量付费附加服务。仅设置告警不能阻止收费，必须同时有平台硬限额（若支持）和应用层上传/生成次数限制。到期前提醒导出数据，未确认付费时停止试用；说明到期后的数据保留/删除规则。

如果免费环境不支持所需运行时或无法安全控制超额，备选是仅保留本地体验或暂时关闭云分割，而非悄悄转为付费。开发者工具的域名校验豁免不能用作手机正式体验版网络方案。
